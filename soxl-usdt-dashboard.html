이 대시보드는 투자 조언이 아니며, 볼린저 밴드/이치모쿠 지표를 정규분포 근사와 결합한 휴리스틱 추정치입니다. 실제 시장은 정규분포를 따르지 않고, 과거 지표 패턴이 미래 확률을 보장하지 않습니다. 참고용으로만 사용하세요. 자동 매매/주문 기능은 포함되어 있지 않으며, 모든 매매 판단과 실행은 사용자 본인의 책임입니다. 이 도구는 Gate.io 공개 시세 API만 사용하며 API 키를 입력받지 않습니다.
